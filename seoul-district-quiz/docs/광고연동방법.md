# 앱인토스 광고 연동 방법

이 문서는 `seoul-district-quiz`에 앱인토스 인앱 광고를 연동할 때 필요한 콘솔 설정, SDK 호출 순서, 구현 예시와 출시 점검 사항을 정리한다.

현재 프로젝트는 `@apps-in-toss/web-framework` 3.1.1을 사용하므로 별도 광고 SDK 설치 없이 다음 API를 사용할 수 있다.

- 전면형 및 보상형 광고: `loadFullScreenAd`, `showFullScreenAd`
- WebView 배너 광고: `TossAds`

`apps-in-toss.config.ts`의 `permissions`에는 광고 권한을 추가하지 않는다.

## 권장 광고 구성

이 게임에는 코스 완료 후 전면형 광고가 가장 자연스럽다. 문제 풀이 중간이나 정답을 확인하는 순간에는 광고를 표시하지 않는다.

- 전면형: 코스 완료 후 다음 화면으로 이동하기 전
- 리워드형: 사용자가 직접 선택하는 `광고 보고 하트 1개 받기` 등의 기능
- 배너: 홈 또는 완료 화면의 상단이나 하단

## 콘솔 준비

1. 앱인토스 콘솔에 사업자 정보를 등록한다.
2. 워크스페이스 정보 탭에서 정산 정보를 입력하고 검토를 요청한다.
3. 광고 메뉴에서 용도별 광고 그룹을 만든다.
   - 예: `게임완료_전면광고`
   - 예: `하트충전_리워드광고`
   - 예: `홈하단_배너광고`
4. 광고 그룹 상세 화면에서 `adGroupId`를 확인한다.
5. 리워드 광고는 실제 서비스에서 지급할 보상 이름과 수량을 콘솔에도 동일하게 입력한다.

광고 그룹 ID가 구글에 등록되기까지 최대 2시간이 걸릴 수 있다. 개발 중에는 반드시 테스트용 광고 그룹 ID를 사용한다. 운영 ID로 개발 테스트를 반복하면 광고 제한이나 제재를 받을 수 있다.

## 전면형 광고 구현

광고는 반드시 다음 순서로 사용한다.

```text
load → loaded 이벤트 → show → dismissed → 다음 load
```

버튼을 누른 뒤 `load`와 `show`를 연속 호출하지 않는다. 화면 진입 전이나 코스 진행 중에 미리 로드해 둔다.

```ts
import {
  loadFullScreenAd,
  showFullScreenAd,
} from '@apps-in-toss/web-framework'

const AD_GROUP_ID = '콘솔에서_발급받은_ID'

let adLoaded = false
let unregisterLoad: (() => void) | undefined

export function preloadCompletionAd() {
  if (!loadFullScreenAd.isSupported()) return

  unregisterLoad?.()
  adLoaded = false

  unregisterLoad = loadFullScreenAd({
    options: {
      adGroupId: AD_GROUP_ID,
    },
    onEvent(event) {
      if (event.type === 'loaded') {
        adLoaded = true
      }
    },
    onError(error) {
      adLoaded = false
      console.error('광고 로드 실패', error)
    },
  })
}

export function showCompletionAd(onFinished: () => void) {
  if (!adLoaded || !showFullScreenAd.isSupported()) {
    onFinished()
    return
  }

  adLoaded = false

  showFullScreenAd({
    options: {
      adGroupId: AD_GROUP_ID,
    },
    onEvent(event) {
      if (event.type === 'dismissed' || event.type === 'failedToShow') {
        preloadCompletionAd()
        onFinished()
      }
    },
    onError(error) {
      console.error('광고 표시 실패', error)
      preloadCompletionAd()
      onFinished()
    },
  })
}
```

컴포넌트가 언마운트될 때 `loadFullScreenAd`가 반환한 등록 해제 함수를 호출한다. 광고 로드나 표시가 실패해도 사용자가 게임을 계속 진행할 수 있어야 한다.

## 리워드 광고 구현

리워드는 `userEarnedReward` 이벤트가 발생했을 때만 지급한다.

```ts
showFullScreenAd({
  options: {
    adGroupId: REWARDED_AD_GROUP_ID,
  },
  onEvent(event) {
    if (event.type === 'userEarnedReward') {
      grantReward(event.data.unitType, event.data.unitAmount)
    }

    if (event.type === 'dismissed') {
      preloadNextRewardedAd()
    }
  },
  onError(error) {
    console.error('리워드 광고 표시 실패', error)
  },
})
```

다음 이벤트에서는 보상을 지급하지 않는다.

- `clicked`
- `impression`
- `dismissed`
- `failedToShow`

광고 클릭 자체를 보상 조건으로 삼거나 `광고 클릭하면 보상 지급` 같은 문구를 쓰면 안 된다.

## 배너 광고 구현

WebView 배너는 `TossAds.initialize()`로 초기화한 뒤 `TossAds.attachBanner()`로 DOM 요소에 연결한다.

```tsx
import { TossAds } from '@apps-in-toss/web-framework'
import { useEffect, useRef } from 'react'

const BANNER_AD_GROUP_ID = '콘솔에서_발급받은_배너_ID'

export function BannerAd() {
  const containerRef = useRef<HTMLDivElement>(null)

  useEffect(() => {
    if (!TossAds.initialize.isSupported()) return

    TossAds.initialize({
      callbacks: {
        onInitialized() {},
        onInitializationFailed(error) {
          console.error('배너 광고 초기화 실패', error)
        },
      },
    })
  }, [])

  useEffect(() => {
    const container = containerRef.current
    if (!container) return

    const banner = TossAds.attachBanner(BANNER_AD_GROUP_ID, container, {
      theme: 'auto',
      callbacks: {},
    })

    return () => banner.destroy()
  }, [])

  return <div ref={containerRef} className="banner-ad" />
}
```

```css
.banner-ad {
  width: 100%;
  min-height: 96px;
}
```

게임 출시 기준에서 배너는 화면 상단 또는 하단에 둔다. 게임 플레이 영역, 정답 버튼이나 다른 CTA에 인접하게 배치해 오클릭을 유도하지 않는다.

## 테스트 방법

1. 브라우저 devtools에서 정상 로드, 로드 실패, 광고 재고 없음 분기를 확인한다.
2. `ads-no-fill` 프리셋으로 No Fill 상황을 확인한다.
3. 광고가 지원되지 않는 환경에서는 게임이 광고 없이 정상 진행되는지 확인한다.
4. 콘솔 QR을 사용해 실제 토스 앱에서 테스트 광고를 확인한다.
5. 광고 표시 전에 로드가 끝났는지 확인한다.
6. 광고 종료 후 미니앱 화면으로 정상 복귀하는지 확인한다.
7. 음악이나 효과음을 추가했다면 광고 재생 중 정지하고 광고 종료 후 재개한다.
8. 리워드 광고는 끝까지 시청한 경우에만 정확히 한 번 보상이 지급되는지 확인한다.

샌드박스 환경에서는 실제 인앱 광고가 지원되지 않을 수 있으므로 최종 확인은 실제 토스 앱에서 진행한다.

## 출시 전 확인 사항

- 테스트용 ID를 운영용 광고 그룹 ID로 교체한다.
- 실제 광고가 중간에 종료되거나 앱을 튕기게 하지 않는지 확인한다.
- 사용자가 예상하기 어려운 순간에 광고가 나오지 않게 한다.
- 광고를 콘텐츠나 게임 버튼처럼 위장하지 않는다.
- 광고 UI의 라벨, CTA, 이벤트 흐름을 임의로 변경하지 않는다.
- 동일 화면에 같은 형식의 광고를 두 개 이상 배치하지 않는다.
- 정상적인 뒤로가기와 화면 종료를 막지 않는다.
- 자동 새로고침이나 인위적인 클릭 및 노출을 만들지 않는다.

## 이 프로젝트에서 함께 수정할 문서

현재 게임물내용설명서에는 광고가 없다고 기재되어 있다. 광고를 실제 빌드에 넣으면 다음 내용도 함께 수정해야 한다.

- 게임물내용설명서의 광고 포함 여부
- 광고 유형과 노출 시점
- 리워드가 있다면 보상 내용과 지급 조건
- 실제 광고 화면 스크린샷
- 등급분류 신청 내용
