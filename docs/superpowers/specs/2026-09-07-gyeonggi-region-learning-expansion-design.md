# 서울·경기 지역 학습 확장 설계

- 작성일: 2026-09-07
- 상태: 사용자 검토 대기
- 기준 문서: `DESIGN.md`

## 1. 배경

현재 서비스는 서울 25개 자치구를 지도에서 맞히는 5문제 퀴즈, 서울 도장깨기, 개인 기록, 25구 타자 도전을 제공한다. 그러나 학습 기록은 자치구를 한 번 맞히면 `masteredDistricts`에 영구 완료로 저장하고, 스트릭은 일일 학습이 아니라 연속 정답 수로 계산한다. 25개 구를 채운 뒤에는 다시 방문할 이유가 약하고, 오래 보지 않은 지역이나 인접 지역 혼동을 다시 학습하는 구조가 없다.

이번 확장은 서울 퀴즈를 유지하면서 경기도를 추가하고, 사용자가 관심 지역과 주변 지역을 반복 학습하도록 경험의 중심을 바꾼다.

## 2. 제품 정의

이 서비스는 사용자가 서울·경기의 행정구역 위치와 인접 관계를 짧은 지도 퀴즈로 익히는 모바일 미니게임이다. 부동산이나 지역에 관심 있는 사용자가 임장 전에 목적 지역과 주변 지역 이름을 익히는 상황을 우선하되, 부동산 정보 서비스가 아니라 지리 학습 서비스로 유지한다.

핵심 약속은 다음과 같다.

> 관심 지역과 주변 지역을 하루 1~2분의 지도 퀴즈로 익힌다.

사용자에게는 `지역구`보다 정확하고 이해하기 쉬운 `지역`, `시·군`, `구`를 사용한다. 국회의원 선거구는 다루지 않는다.

## 3. 목표와 비목표

### 목표

- 기존 서울 25구 학습 경험과 기록을 유지한다.
- 경기도 31개 시·군을 전체 지도에서 구분할 수 있게 한다.
- 관심 도시의 내부 구와 인접 지역을 함께 익히게 한다.
- 한 번의 정답이 아니라 반복 정답과 시간 경과로 숙련도를 판단한다.
- 복습할 이유가 홈에 명확히 나타나는 재방문 루프를 만든다.
- 전체 지도, 강조 지도, 개별 지역 실루엣이 같은 경계 데이터를 사용하게 한다.

### 비목표

- 실거래가, 시세, 교통 호재, 투자 추천을 제공하지 않는다.
- `인기 지역 순위`나 `임장 추천 지역`을 단정하지 않는다.
- 첫 버전에 로그인, 기기 간 동기화, 푸시 알림을 넣지 않는다.
- 리그, 친구 경쟁, 광고, 결제를 추가하지 않는다.
- 첫 버전에서 경기 외 지역으로 확장하지 않는다.

## 4. 정보 구조

서비스는 두 개의 지역팩을 가진다.

| 지역팩 | 기본 범위 | 세부 범위 |
| --- | --- | --- |
| 서울 | 25개 자치구 | 기존 서울 퀴즈와 도장깨기 |
| 경기 | 31개 시·군 | 수원·성남·용인의 일반구와 인접 지역 코스 |

홈에서는 지역팩을 선택하게 하기보다 오늘 할 일을 먼저 보여준다.

1. 복습할 문제가 있으면 `오늘의 5문제`를 Primary CTA로 표시한다.
2. 최근 학습한 지역과 숙련도 변화를 보여준다.
3. 서울과 경기의 전체 학습 현황을 나란히 보여준다.
4. `새 지역 찾아보기`를 Secondary CTA로 제공한다.

## 5. 핵심 사용자 흐름

### 신규 지역 학습

1. 홈에서 `새 지역 찾아보기`를 선택한다.
2. 서울 또는 경기 지도를 선택한다.
3. 지도 탭이나 이름 검색으로 관심 지역을 고른다.
4. 해당 지역의 학습 범위와 예상 문제 수를 확인한다.
5. 위치, 내부 구, 인접 지역 순으로 5문제를 푼다.
6. 완료 화면에서 숙련도 변화와 다시 볼 지역을 확인한다.

### 재방문 복습

1. 홈에서 `오늘의 5문제`와 복습 대상 수를 확인한다.
2. 관심 지역 2문제, 인접 지역 2문제, 오래됐거나 틀린 지역 1문제를 푼다.
3. 최대 2개의 오답은 세트 끝에 채점하지 않는 확인 문제로 다시 본다.
4. 완료 화면에서 숙련도 변화와 다음 복습 시점을 확인한다.

### 서울 기존 사용자

1. 기존 서울 기록을 새 학습 기록 구조로 이전한다.
2. 홈에서 서울 학습 진척을 그대로 확인한다.
3. 경기 지역팩을 선택해 새 코스를 시작할 수 있다.

## 6. 문제 유형

| 유형 | 화면 | 학습 목적 |
| --- | --- | --- |
| 위치 인식 | 지역이 강조된 전체 지도에서 이름 선택 | 경기도 안의 상대 위치 기억 |
| 위치 회상 | 지역명을 보고 전체 지도에서 영역 선택 | 이름에서 위치를 떠올리는 회상 |
| 실루엣 | 주변 맥락 없이 개별 지역 모양을 보고 이름 선택 | 지역 형태 구분 |
| 내부 구 | 도시 확대 지도에서 일반구 선택 | 수원·성남·용인 내부 구조 학습 |
| 인접 지역 | 목표 지역과 맞닿은 시·군·구 선택 | 임장 전 주변 관계 학습 |
| 주관식 | 강조된 지역 이름 직접 입력 | 가장 강한 이름 회상 |

초기 코스는 쉬운 인식 문제에서 시작해 지도 선택과 주관식 회상으로 진행한다. 한 세트 안에서 난도가 갑자기 뛰지 않도록 사용자의 현재 숙련 단계가 허용하는 유형만 출제한다.

## 7. 지도 표현

### 공통 원칙

- 서울 문제는 서울 외곽선과 25개 자치구만 보여준다.
- 경기 문제는 한반도나 전국 지도가 아니라 경기도 외곽선과 31개 시·군만 보여준다.
- 경기도 전체 단계에서는 일반구가 있는 도시도 하나의 시 경계로 합쳐 내부 구 경계를 숨긴다. 도시 세부 단계에 들어가야 일반구 경계를 보여준다.
- 서울과 맞닿은 경기 지역의 인접 문제는 두 지역팩의 경계를 함께 자른 국소 지도를 사용할 수 있다. 이때도 전국 locator map은 사용하지 않는다.
- 목표 지역은 전체 지도에서 단청 레드로 강조한다.
- 인접 지역은 한 단계 약한 한강 블루 계열로 표시한다.
- 정오답 후에는 성공·오류 색과 아이콘·문구를 함께 사용한다.
- 지역 카드의 그림은 제네릭 지도 핀이 아니라 실제 행정경계 실루엣을 사용한다.

### 데이터 원칙

- 원본은 GeoJSON 또는 TopoJSON으로 관리하고 React에서 SVG로 렌더링한다.
- 전체 지도와 개별 실루엣은 같은 원본에서 생성한다.
- 각 도형은 안정적인 행정구역 ID, 한글 이름, 계층, 기준일을 가진다.
- 인접 관계는 경계선을 공유하는 지역으로 정의하며 꼭짓점만 닿는 지역은 제외한다. 서울·경기 사이의 인접 관계도 같은 기준으로 연결한다.
- 경계 데이터에는 출처 URL, 기준일, 라이선스, 가공 절차를 함께 기록한다.
- 구현 착수 시 최신 공식 행정경계 데이터를 확보해 경기도 31개 시·군과 세부 구를 검증한다.
- 와이어프레임에 사용한 과거 데이터는 제품 자산으로 재사용하지 않는다.

### 접근성

- 각 지역 도형은 키보드 Enter·Space와 탭으로 선택할 수 있다.
- 모든 지역은 한글 `aria-label`과 가시적인 포커스 링을 가진다.
- 지도와 동일한 기능을 제공하는 지역명 목록 또는 검색 경로를 함께 둔다.
- 색만으로 선택, 인접, 정답, 오답 상태를 구분하지 않는다.
- 터치 대상이 작은 지역에는 최소 44px의 투명 히트 영역이나 확대 진입을 제공한다.

## 8. 학습과 복습 모델

지역마다 하나의 숙련 단계를 가진다.

| 단계 | 사용자 표현 | 진입 조건 | 다음 복습 |
| --- | --- | --- | --- |
| 0 | 처음 봄 | 기록 없음 또는 오답으로 단계 0 도달 | 다음 세트 우선 |
| 1 | 익히는 중 | 단계 0에서 정답 | 1일 뒤 |
| 2 | 익숙해지는 중 | 단계 1에서 정답 | 3일 뒤 |
| 3 | 익숙함 | 단계 2에서 정답 | 7일 뒤 |
| 4 | 잘 알고 있음 | 단계 3 이상에서 정답 | 21일 뒤 |

정답이면 한 단계 상승하고 오답이면 한 단계 하락한다. 단계는 0~4 범위를 벗어나지 않는다. 단계 3 이상으로 올라가는 정답은 이전 정답과 다른 세션에서 얻어야 하며, 한 세트의 반복 문제만으로 높은 숙련도를 만들 수 없다.

세부 규칙은 다음과 같다.

- 오답 지역은 세트가 끝날 때 최대 2개까지 채점 없는 확인 문제로 다시 보여준다.
- 확인 문제의 정답은 숙련 단계를 올리지 않는다.
- 복습 예정일이 지난 지역을 먼저 출제한다.
- 복습 대상이 5개보다 적으면 최근 관심 지역 중 숙련도가 낮은 지역으로 채운다.
- 동일 지역은 한 세트의 채점 문제에 한 번만 등장한다.
- `구` 생략을 허용하는 기존 서울 주관식 정규화 규칙을 경기 시·군·구에도 적용한다.

연속 정답과 일일 스트릭은 분리한다.

- 콤보: 한 세트 안의 연속 정답 수
- 학습 스트릭: 현지 시간 기준 하루에 한 세트를 완료한 연속 일수
- 기존 `currentCorrectStreak`와 `bestCorrectStreak`는 콤보 기록으로 이전한다.
- 과거 완료 날짜가 없으므로 기존 데이터에서 학습 스트릭을 추정하지 않는다.

## 9. 화면 설계

### 홈

- `오늘의 5문제`를 가장 먼저 보여준다.
- 최근 학습 지역과 숙련도 변화를 표시한다.
- 서울 25구와 경기 31시·군의 진행 현황을 분리해 표시한다.
- 복습이 없으면 `새 지역 찾아보기`가 Primary CTA가 된다.

### 지역 선택

- 서울/경기 탭, 지역명 검색, 인터랙티브 지도를 제공한다.
- 경기 탭에서는 경기도 외곽선과 내부 시·군만 보인다.
- 수원·성남·용인은 `세부 지역 코스`가 있음을 표시한다.
- 나머지 지역도 위치와 인접 지역 코스를 시작할 수 있다.

### 퀴즈

- 문제 유형, 진행도, 하트, XP, 콤보를 표시한다.
- 지도를 가장 큰 시각 요소로 유지한다.
- 전체 지도 문제와 개별 실루엣 문제에 동일한 경계 데이터를 사용한다.
- 정오답 후 정답명과 위치·인접 관계에 관한 한 줄 단서를 제공한다.

### 완료

- 총점보다 목표 지역의 숙련도 변화를 먼저 보여준다.
- `다시 보면 좋은 지역`을 최대 3개 표시한다.
- 다음 복습 시점을 부담 없는 문구로 안내한다.
- Primary CTA는 홈으로 돌아가기가 아니라 상황에 따라 `오늘 학습 마치기` 또는 `다음 지역 익히기`가 된다.

## 11. 기록 마이그레이션

기존 `PersonalRecordsV1`을 새 버전으로 읽을 수 있어야 한다.

- `masteredDistricts`의 각 서울 자치구를 안정적인 서울 지역 ID로 변환한다.
- 변환된 지역은 단계 1, 정답 1회로 저장한다.
- 과거 풀이 시간이 없으므로 `lastAnsweredAt`은 `null`로 둔다.
- 해당 지역은 복습 후보가 되지만 하루에 최대 5개만 출제한다.
- 모드별 완벽 세트 최단 기록을 보존한다.
- 현재·최고 연속 정답을 콤보 기록으로 보존한다.
- 마이그레이션 결과를 저장하기 전에 모든 지역 ID를 검증한다.
- 일부 항목이 잘못돼도 전체 기록을 초기화하지 않고 유효한 항목만 이전한다.

## 12. 오류와 빈 상태

| 상황 | 동작 |
| --- | --- |
| 지도 로딩 실패 | 지역명 목록과 `다시 불러오기` 제공 |
| 특정 도형 누락 | 해당 문제를 출제 대상에서 제외하고 오류 기록 |
| 기록 불러오기 실패 | 빈 기록으로 퀴즈 허용, 재시도 경로 제공 |
| 기록 저장 실패 | 현재 세트 유지, 저장 실패 안내, 다음 저장 시 재시도 |
| 복습 대상 부족 | 관심 지역의 낮은 숙련도 문제로 채움 |
| 문제 생성 불가 | 선택 지역 화면으로 돌아갈 수 있는 설명과 CTA 제공 |
| 행정구역 데이터 불일치 | 배포 전 검증 실패로 처리 |

| `storage` | 학습 기록과 복습 일정의 기기 내 저장 | 없음 | 없음 |
| `analytics` | 화면, 클릭, 코스 시작·완료, 복습 이벤트 | 없음 | 없음 |
| `haptic` | 정오답의 보조 피드백 | 없음 | 없음 |

출시에는 모든 미니앱의 기본 게이트인 `BIZ_WORKSPACE` 약관이 필요하다. 이번 범위는 로그인, 광고, 결제를 포함하지 않으므로 `TOSS_LOGIN`, `IAA`, `IAP` 약관을 추가하지 않는다. 푸시 알림도 사용하지 않는다.

## 15. 검증과 테스트

### 데이터 검증

- 경기 최상위 학습 대상이 정확히 31개 시·군인지 확인한다.
- 모든 지역 ID와 `geometryId`가 유일한지 확인한다.
- 인접 관계가 양방향인지 확인한다.
- 세부 구가 올바른 상위 도시에 속하는지 확인한다.
- 경계 데이터의 기준일과 출처가 비어 있지 않은지 확인한다.

### 학습 로직 테스트

- 정답과 오답에서 숙련 단계가 경계를 벗어나지 않는다.
- 단계별 다음 복습일이 1·3·7·21일 규칙을 따른다.
- 확인 문제는 숙련도를 올리지 않는다.
- 세트가 2·2·1 구성과 지역 중복 금지를 지킨다.
- 복습 대상 부족 시 낮은 숙련도 문제로 채운다.
- `구` 생략과 한글 공백을 정규화한다.

### 마이그레이션 테스트

- 유효한 서울 기록과 최단 기록을 보존한다.
- 잘못된 자치구 이름만 제외한다.
- 같은 기록을 두 번 마이그레이션해도 중복되지 않는다.
- 저장 실패 시 원본 V1 기록을 손상시키지 않는다.

### UI와 접근성 테스트

- 320px 화면에서 지도, 답안, CTA가 잘리지 않는다.
- 지도 도형과 지역 목록을 키보드로 선택할 수 있다.
- 정오답과 선택 상태가 색 없이도 이해된다.
- 모션 감소 환경에서 흔들림과 파티클을 제거한다.
- 지도 실패 상태에서도 퀴즈를 종료하거나 다시 시도할 수 있다.

## 16. MVP와 후속 범위

### MVP

- 기존 서울 기능 유지
- 경기 31개 시·군 전체 지도와 위치 문제
- 수원·성남·용인 세부 구 코스
- 모든 경기 시·군의 기본 인접 지역 문제
- 지역 검색과 최근 학습 지역
- 지역별 숙련도와 오늘의 복습
- V1 기록 마이그레이션
- 분석 이벤트와 오류 상태

### 후속

- 고양·안양·안산·부천 등 추가 세부 구 코스
- 로그인과 기기 간 기록 동기화
- 선택형 푸시 복습 알림
- 경기 밖의 새 지역팩

후속 항목은 별도 설계와 승인 없이 MVP에 포함하지 않는다.

## 17. 성공 지표

출시 전 수치 목표를 임의로 만들지 않고 현재 서울 버전의 기준값을 먼저 측정한다. 이후 다음 변화를 본다.

- 첫 지역 코스 시작률과 완주율
- 완료 후 다른 지역 코스 시작률
- 복습 대상 사용자 중 복습 세트 시작률과 완주율
- 동일 지역의 첫 시도 대비 반복 학습 정답률 변화
- 인접 지역 문제의 반복 오답 감소율
- 기존 서울 사용자 중 경기 지역팩 진입률
- 지도 직접 선택과 검색의 사용 비율
- 지도 오터치와 로드 실패율

속도나 총 플레이 횟수보다 복습 재방문과 지역 구분 능력의 개선을 우선한다.
