# 오늘의 복습 기능 설계

## 확정 범위

- 첫 출시는 광고 없이 진행한다.
- 홈에서는 새 지역 학습을 먼저 제공하고, 그 아래에 오늘의 복습 카드를 둔다.
- 복습 예정일이 오래 지난 지역부터 최대 5개만 출제한다.
- 예정 지역이 5개보다 적으면 있는 지역만 출제한다.
- 복습 간격은 숙련도에 따라 1일, 3일, 7일, 14일이다.
- 날짜 경계는 기기의 현지 자정을 따른다.
- 복습 오답은 정답 지역을 보여준 뒤 다른 문제 뒤에 다시 출제한다.
- 한 지역만 남으면 학습 안내 뒤 다시 출제한다.
- 지역별 직접 시도는 최대 5회다.
- 최초 정답은 10 XP, 재출제 정답은 5 XP다.
- 복습 정답 하나마다 하트 1개를 최대 3개까지 회복한다.
- 오늘의 복습 대상이 없으면 `오늘 복습 완료`를 표시한다.
- 푸시 알림은 지원하지 않는다.

## 숙련도

- 새 지역 학습의 기존 단계 진입 규칙은 유지한다.
- 오늘의 복습에서는 서로 다른 현지 날짜의 정답 2회가 누적되면 한 단계 오른다.
- 오늘의 복습에서는 서로 다른 현지 날짜의 오답 2회가 누적되면 한 단계 내린다.
- 최초 오답은 기록하며 같은 세션의 교정 정답이 최초 결과를 덮어쓰지 않는다.

## 후속 광고 버전

- 하트가 0일 때만 보상형 광고를 노출한다.
- 광고 1회당 하트 1개, 하루 최대 3회다.
- 광고 실패 시 복습 진입 경로를 제공한다.
- 광고 배포 전에 실기기 검증과 제출 문서를 갱신한다.
